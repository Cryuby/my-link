Overview

참고는 구조만, 화면은 다른 방향으로.

상단 소개와 시각적 미리보기, 중간 기능 설명, 마지막 제출 정보까지 자연스럽게 이어지는 랜딩 흐름을 만들었습니다. 대신 색상, 카드 형태, 간격, 타이포그래피 리듬은 지금 사이트에 맞게 새로 잡았습니다.

이 페이지에서 바로 보이는 것

  • 이 사이트가 무엇인지 첫 화면에서 바로 이해되도록 구성
  • 모바일에서도 한 화면씩 차례대로 읽히는 세로 중심 레이아웃
  • Vercel 정적 배포에 맞는 단일 HTML 구조

이번 구성에서 바꾼 점

따뜻한 크림 톤 대신 민트 기반의 밝은 인터페이스를 사용했고, 종이 카드 느낌보다 유리 패널과 디바이스 프리뷰 중심으로 재구성했습니다. 랜딩 페이지이면서도 과제 제출용 사이트라는 목적이 흐려지지 않도록 카피를 단순하게 유지했습니다.

Features

이 랜딩 페이지에 들어간 핵심 블록

01

첫 화면 메시지

방문자가 접속하자마자 이 사이트가 과제 제출용 마이링크 웹사이트라는 점을 명확하게 읽을 수 있도록 큰 헤드라인을 배치했습니다.

02

모바일 프리뷰 카드

실제 마이링크 서비스처럼 보이는 디바이스 프리뷰를 두어 단순 문구 페이지보다 랜딩 사이트 느낌이 나도록 구성했습니다.

03

제출용 정보 구역

저장소와 배포 링크를 어디에 적어야 하는지 마지막 섹션에서 다시 정리할 수 있게 제출 목적의 정보 블록을 따로 뒀습니다.
